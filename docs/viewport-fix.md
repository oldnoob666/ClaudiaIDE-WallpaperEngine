# 3.1.52.6：壁纸固定在编辑区

已安装到本机 VS 2022。

原版静态图片使用编辑器背景画刷；本次动态层在每次布局更新时错误地回到文档坐标起点，导致往下滚动时壁纸上移并消失。

新版把动态层定位到当前视口原点，尺寸跟随编辑区。上下、左右滚动只移动代码；壁纸保持原位，视频或场景动画继续播放，不会因为滚动重新加载。

验证：

- WPF 回归测试先复现向下滚动300px后背景坐标变为-300，再确认修复后垂直/水平滚动、改变尺寸和返回起点均保持覆盖视口。
- 实际 VS 连续滚动95行，视口向下移动1615逻辑像素，背景仍在可见区原点（布局取整误差小于1像素）。
- 实际横向滚动约9977逻辑像素，背景仍在可见区原点，动画约30 FPS。
- 已保存原文件修改，并恢复原文件及光标位置。

安装包、源码 ZIP 和补丁均已更新到3.1.52.6。之前的无窗口查询及首屏加载修复保留。
