# 壁纸扩展到行号与断点栏

3.1.52.9 已安装到本机 VS 2022。

同一个动态播放器现在位于包含行号、断点栏和代码区的编辑器底层，画面连续覆盖左侧黑色区域。编辑器边栏与代码区的底色透明，行号、图标、代码和输入操作保留。上下、左右滚动不会移动整张壁纸。

播放器没有复制成两份，动画和原有35%透明度保留。切换回普通图片模式或关闭视图时，会移除动态层并恢复原底色；回收的边栏标记控件也会及时释放。

验证包括：完整边栏与代码区覆盖、滚动与尺寸变化、编辑器自身底色透明、图标输入属性、关闭时底色恢复，以及回收标记控件恢复。实际 VS 截图见“含行号栏实测.png”；滚动后背景仍固定在整个编辑区原点，动画约30 FPS。

安装包、源码和补丁已同步更新。顶部菜单、窗口工具栏与外部工具窗口保持正常界面。
