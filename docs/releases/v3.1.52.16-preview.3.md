# 3.1.52.16 Preview 3：脚本切换休眠与黑屏优化

这是测试版（Pre-release），延续工具窗口透明功能，保留 Preview 2 的代码区鼠标点击修复。稳定下载入口继续指向 [3.1.52.13](https://github.com/oldnoob666/ClaudiaIDE-WallpaperEngine/releases/tag/v3.1.52.13)。

## 更新内容

- 频繁切换脚本时，保留已加载标签的独立播放器和动画状态，短期切回复用，减少重复加载。
- 连续 60 秒没有切换脚本，内部自动释放隐藏标签的播放器，只保留当前可见编辑区；分屏中所有可见编辑区继续播放。休眠不显示提示，不需要设置。
- 关闭标签、最小化或隐藏窗口、关闭背景时仍及时释放。休眠后首次切回已释放的标签，需要重新加载壁纸。
- 共享主窗口背景在标签显示、获得焦点和编辑器背景变化时，于下一次绘制前更新透明背景，修复等待一秒周期刷新而短暂露出深色底色的问题。一秒轮询保留为兜底。
- 保留原有首帧保护、延后拆卸防崩溃处理、代码区鼠标命中和关闭透明开关后的背景还原。

## 安装

下载附件 `ClaudiaIDE-WallpaperEngine-3.1.52.16.vsix`，关闭所有 Visual Studio 窗口后双击安装，再重新打开 VS。可以从 Preview 1、Preview 2 或此前版本升级；不要用 `Source code` 替代安装包。

需要 Windows x64、Visual Studio 2022、Wallpaper Engine 和 WebView2 Runtime。

首次启用：**扩展 → ClaudiaIDE → 启用 Wallpaper Engine 动态背景…**。

工具窗口透明开关位于 **扩展 → ClaudiaIDE → 打开设置 → 当前浅色/深色主题设置 → 工具窗口背景透明**，默认关闭。关闭后恢复原有外观。主窗口共享播放器模式无需为每个停靠标签缓存播放器；独立编辑区及浮动编辑器使用上述 60 秒休眠策略。

## 验证

- 239 项检查通过：独立播放器与真实 60 秒休眠 115 项、共享播放器与首帧透明化 29 项、配置与路径 47 项、播放器脚本 10 项、启动 6 项、滚动布局 7 项、工具窗口与鼠标命中 25 项。
- 首帧回归检查停用每秒轮询，在实际 WPF 绘制前验证标签显示、背景重置、获得焦点及新视图加载，避免周期刷新掩盖黑屏。
- 本机 VS 2022 已完成升级安装，安装后的 DLL、播放器脚本与构建一致，原配置保留；实际脚本切换检查及使用者复测通过。
- 附件 `SHA256SUMS.txt` 可用于核对安装包。

本次验证范围为本机 Windows x64 / VS 2022。后台动画帧率仍受 WebView2 调度影响，复杂场景兼容性取决于 WebWallGL；休眠后首次加载仍有初始化成本。
