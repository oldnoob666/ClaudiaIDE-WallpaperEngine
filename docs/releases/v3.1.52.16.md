# 3.1.52.16 正式版：工具窗口透明与脚本切换优化

将 Preview 3 转为正式发布，汇总此前三个预览版的工具窗口透明、代码区鼠标操作修复、播放器休眠和标签切换黑屏修复。正式版复用 Preview 3 的同一份 VSIX，内部版本仍为 `3.1.52.16`；已安装 Preview 3 的用户无需重装。

## 下载与安装

下载本页 Assets 中的 **ClaudiaIDE-WallpaperEngine-3.1.52.16.vsix**，关闭所有 Visual Studio 窗口后双击安装，再重新打开 VS。旧稳定版 3.1.52.13、Preview 1 和 Preview 2 用户可升级。`Source code` 是开发源码，普通用户无需下载。

需要 Windows x64、Visual Studio 2022、Wallpaper Engine 和 WebView2 Runtime。安装包包含播放器、查询工具和 WebWallGL，运行时无需 Node.js 或编译工具。

首次启用：**扩展 → ClaudiaIDE → 启用 Wallpaper Engine 动态背景…**。

工具窗口透明：**扩展 → ClaudiaIDE → 打开设置 → 当前浅色/深色主题 → 工具窗口背景透明**，设为 `True` 后应用。默认关闭，浅色/深色主题分别保存；关闭后恢复原有外观。

## 相比上一正式版的更新

- 可选工具窗口背景透明：主窗口停靠区共用一张动态壁纸，输出、解决方案资源管理器、错误列表等工具窗口透出连续背景，保留文字、选中高亮和输入控件样式。
- 修复透明模式下代码区点击、双击选词和跨行拖选被装饰层拦截的问题。
- 频繁切换脚本时，保留已加载标签的独立播放器和动画状态，短期切回复用，减少重复加载。
- 连续 60 秒没有切换脚本后，自动释放隐藏标签的播放器，只保留可见编辑区；分屏中所有可见编辑区继续播放。主窗口共享播放器模式无需为停靠标签分别缓存，浮动编辑器仍使用独立播放器策略。
- 修复共享背景在切换脚本标签时短暂露出深色底色的问题，在标签显示、获得焦点和背景变化时及时更新透明背景。
- 保留首帧就绪后显示、延后拆卸防崩溃处理，以及关闭视图、最小化 VS 或隐藏背景时及时释放资源的行为。
