# 3.1.52.17 正式版：修复灯泡菜单导致 VS 卡住

修复开启「工具窗口背景透明」后，点击代码修复灯泡、展开建议菜单时可能使整个 Visual Studio 界面无法操作的问题。触发问题只需要展开菜单，不必执行「使用 Copilot 修复」。

## 下载与安装

下载本页 Assets 中的 **ClaudiaIDE-WallpaperEngine-3.1.52.17.vsix**，关闭所有 Visual Studio 窗口后双击安装，再重新打开 VS。建议 3.1.52.16 及更早版本用户升级。`Source code` 是开发源码，普通用户无需下载。

正式版与本次已安装并复测通过的 3.1.52.17 本地修复包完全一致，已安装该修复包无需重装。需要 Windows x64、Visual Studio 2022、Wallpaper Engine 和 WebView2 Runtime。

## 修复内容

- 灯泡菜单中的临时预览编辑器保留原有背景，不再被主窗口的壁纸透明逻辑反复修改。
- 修复背景透明化与恢复互相触发刷新、持续占用界面线程的问题，菜单展开后可正常关闭并继续操作代码。
- 保留工具窗口透明、代码区点击与拖选、脚本切换时的首帧透明化、播放器复用和 60 秒休眠行为。
