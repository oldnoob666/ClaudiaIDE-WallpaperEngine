# 3.1.52.13 · 推广稳定版

在 Visual Studio 2022 编辑器中跟随 Wallpaper Engine 当前壁纸，支持视频和部分动态场景。

## 下载与安装

请下载本页 Assets 中的 **ClaudiaIDE-WallpaperEngine-3.1.52.13.vsix**，关闭 Visual Studio 后双击安装，再重新打开 VS。`Source code` 是开发源码，普通用户不用下载或编译。

需要 **Windows x64、Visual Studio 2022、已安装的 Wallpaper Engine 和 Microsoft WebView2 Runtime**。无需 Node.js、npm 或 Visual Studio 扩展开发工作负载。安装包不包含 Wallpaper Engine 或工坊壁纸素材。

已安装原版 ClaudiaIDE 时，建议先在 VS 扩展管理器卸载原版，关闭 VS 完成卸载，再安装本版。本版沿用原扩展身份，按替换版使用，不要同时启用两版。

## 本版改动

- 新增“扩展 → ClaudiaIDE → **启用 Wallpaper Engine 动态背景…**”入口，集中检查安装目录、当前用户壁纸、显示器和 WebView2。
- 检查通过后点击“启用当前壁纸”即可保存深浅主题设置；支持手动选择目录和显示器，显示器失效时要求重新选择。
- 目录或配置错误、素材缺失、不支持类型、视频/场景加载失败及 WebView2 问题有明确指引，窗口提供教程、Runtime 下载和日志入口。
- 当前解决方案使用独立配置时，联动可在本次会话保持；不会自动改写 `.claudiaide` 文件。需要持久保存时使用“保存解决方案设置”。
- 首页提供直接下载、真实效果图、三步启用说明与常见问题。
- 保留可见编辑区才加载、隐藏/最小化释放播放器及首帧就绪后显示的行为。

在 Wallpaper Engine 中应用壁纸后，打开代码文件，使用上述菜单检测并启用。`Ctrl+Shift+Alt+C` 显示/隐藏；透明度在 ClaudiaIDE 浅色/深色主题设置中调整。

[完整安装与常见问题](https://github.com/oldnoob666/ClaudiaIDE-WallpaperEngine/blob/main/docs/quick-start.md) · [反馈问题](https://github.com/oldnoob666/ClaudiaIDE-WallpaperEngine/issues)

## 兼容与验证范围

当前验证为本机 Windows x64 / Visual Studio 2022，包括升级安装、真实菜单/启用窗口和场景显示、配置与路径测试、播放错误测试、解决方案设置回归及播放器生命周期回归。未在另一台无开发环境的电脑、ARM64 或物理多显示器热插拔条件下验证；显示器失效使用临时配置模拟。

WebWallGL 为第三方场景渲染器，不保证兼容全部工坊场景。Application 壁纸不执行，Web 壁纸需要 HTML 入口。各编辑区独立播放，播放进度不与桌面同步。

这是基于 [buchizo/ClaudiaIDE](https://github.com/buchizo/ClaudiaIDE) 的非官方衍生版，使用 [WebWallGL](https://github.com/oneincase/webwallgl) 渲染场景，与 ClaudiaIDE 原作者及 Wallpaper Engine 官方无隶属关系。许可证和第三方声明随安装包提供。
